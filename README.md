# 图像渐变动画软件

Windows原生桌面程序，使用C++17和系统组件实现。

## 功能

- 读取同尺寸起始BMP与终止BMP
- 设置过渡间隔数和播放间隔
- 逐通道计算RGB线性插值
- 播放、暂停、继续和重播
- 显示起始、当前与终止图像
- 导出含首尾帧的24位BMP序列

## 编译与运行

准备Windows x64和MinGW-w64 C++工具链，在项目目录执行：

```powershell
.\build.ps1 -Compiler "C:\mingw64\bin\g++.exe"
.\ImageMorph.exe
```

也可将g++加入PATH后运行 `.\build.ps1`。工程另提供CMake配置。

## 操作

打开两幅同尺寸BMP，设置1至300个过渡间隔及10至5000毫秒帧间隔。点击播放或暂停，导出时在“实验结果/帧序列_N段”生成N+1幅BMP及参数文件。

## 示例

“实验素材”内提供两幅程序生成的彩色渐变BMP，可直接演示。
